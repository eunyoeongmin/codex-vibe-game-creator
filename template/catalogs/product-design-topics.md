# 제품 설계 category·topic 표

게임 제작 AI가 사용자 결정의 `category`와 `topic`을 고를 때 사용하는 기준표다. 각 표의 제목이 category이며, 첫 번째 열의 이름을 topic으로 저장한다. 두 번째 열은 무엇을 정할지 설명하며 결정값이나 기본값이 아니다.

## 사용과 추가 방법

- 현재 게임에 필요한 topic을 골라 사용한다. 표 전체를 필수 질문 목록으로 삼지 않는다. 질문·확정·저장은 `AGENTS.md`의 규칙을 따른다.
- 먼저 같은 의미의 topic이 표와 기존 결정에 있는지 확인한다. 있으면 그 topic을 사용하고, 표현만 다른 중복 항목을 만들지 않는다.
- 표에 없는 새로운 사항이 필요하면 `AGENTS.md`의 [topic 추가 기록](../guide/topic-additions.md#topic-추가-기록) 절차에 따라 `decisions.py topic add`로 해당 category에 행을 추가하고 근거를 함께 저장한 뒤 사용한다. 기존 category에 맞지 않으면 `other`에 추가한다.
- topic은 결정값이 아니라 정할 사항의 이름으로 쓴다. 예: `승리 조건`은 topic, `보스를 쓰러뜨리고 출구에 도달`은 decision이다.
- 새 topic을 추가해도 사용자 결정이 확정되는 것은 아니다. 값과 status는 실제 사용자 발언과 기존 확정 판단 규칙에 따라 저장한다.
- 수량·시간·인원·성능을 고르는 후보에는 단위와 구체적인 수치를 쓴다. 사용자에게 해당하지 않는 기능이나 규모를 기본으로 넣지 않는다.
- 여러 플랫폼·모드·에셋에 서로 다른 선택을 하는 경우, 같은 topic의 decision 안에서 적용 대상을 구분한다. 하나의 선택으로 임의 축소하지 않는다.
