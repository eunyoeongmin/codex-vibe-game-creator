# Codex Vibe Game Creator

会話から、自分だけのゲームを。アイデアを伝え、Codexと企画を固めて、ローカルのWeb工房で制作・試遊できます。

[한국어](README.ko.md) · [English](../README.md) · 日本語 · [简体中文](README.zh-Hans.md) · [繁體中文](README.zh-Hant.md)

OpenAIの公式製品ではない、独立したコミュニティプロジェクトです。

## ダウンロードと起動

**[最新版をダウンロード](https://github.com/eunyoeongmin/codex-vibe-game-creator/releases/latest)**

1. **Windows 10/11 x64**で `-setup.exe` をダウンロードして実行します。Git・Node.js・Codexデスクトップアプリの事前インストールは不要です。
2. ランチャーがアプリを展開し、Python 3.12、必要なパッケージ、多言語検索モデルを準備します。既存のCodex実行ファイルがなければCodex CLIもインストールします。インターネット接続が必要です。初回は数分以上かかる場合があり、進捗はセットアップ画面に表示されます。
3. ブラウザーで開いたダッシュボードから、自分のChatGPTアカウントでCodexにログインします。Windowsサンドボックス設定の管理者確認が出たら完了してください。使えるモデルや利用上限はアカウントによって異なります。
4. 言語を選び、新しいプロジェクトに名前を付け、作りたいゲームを説明します。

次回からはデスクトップの **Codex Vibe Game Creator** ショートカットで起動します。実行ウィンドウを閉じるとサーバーも終了します。ZIP版は展開して `start.bat` を実行してください。

プレイ保存・実行地点、ゲーム翻訳、条件を揃えたプレイ比較、システム連携設計、コンテンツごとのプレイ差分表を利用できます。保存にはゲーム固有の capture/restore アダプターが必要で、AIに実際の状態との連携を依頼できます。変換時も元のセーブを残します。翻訳はゲームが使う登録済みJSONを編集し、翻訳漏れ・変数の不一致と現在表示されているDOM文言のはみ出しを確認します。設計案・ユーザー選択・実装根拠を区別して決定記録につなぎます。面白さや満足度は自動判定しません。

サウンド演出では登録音源の使用場面、ループ、フェード、同時再生、優先度、音声中のBGM低減を管理し、試聴後にゲームイベントへの連携を依頼できます。ゲームバランスは実際のゲーム計算関数で入力と目標範囲を比較し、根拠と結果を保存します。比較だけでゲームの数値は変更せず、調整依頼で適用します。

## 制作ツール

右側の制作ツールから、登録したJSON/CSVの行編集、画像・説明・任意のゲーム状態を含むプレイフィードバック、制作チェックポイントの保存と復元、別フォルダーの比較案の実行と採用、独立したストーリー記録、ゲームZIPの書き出しを利用できます。

データはAIに実際のゲームファイルを登録させてから編集します。復元・比較案の採用前に現在のファイルを保存します。会話履歴は戻しません。ストーリーはAIの提案をユーザーが確定し、確定だけではコードを変更しません。状態の取得にはゲーム側の `GameCreatorFeedback()` が必要です。書き出しは選択したHTMLのフォルダーが対象です。エンジンのWeb出力は先にビルドしてください。


静止画の範囲を指定した変更依頼と前後比較、根拠付きのデータ関係表示、台詞・移動・画像・音・転換・待機を並べる演出タイムラインを利用できます。ゲーム内プレビューと再利用可能な実行ファイルの出力に対応します。Canvasやエンジンの対象は接続依頼でアダプターを実装します。静止画の取得はゲーム自体を一時停止しません。

## 制作の流れ

プレビューの **プレイしながら制作** でゲームと編集ツールを並べて開けます。最初にAIへ実際の対象と状態の接続を依頼します。対象選択 → 動作記録 → 地点保存 → 編集依頼または変更案作成と進め、同じ保存状態から比較して採用できます。**システム関連図** はシステムやステージ・イベント・報酬・解放の関係を表示し、設計・コード根拠・実際の観察を区別します。既存ゲームにもアダプター接続が必要で、任意のゲーム状態を自動推測しません。

- 会話でジャンル、コアループ、操作、画風、規模を具体化します。選択カードには自由入力もできます。
- ユーザーの決定、AIの制作上の選択と根拠、参考資料を分けて記録し、原文を保持します。
- DBから作成した企画のまとめと `SPEC.md` を確認・承認し、続いてマイルストーン全体の計画を承認します。
- 進捗タブでは完了したマイルストーンと現在の作業数を確認できます。記録がなければ推測の進捗率は表示しません。
- HTMLゲームのプレビュー、テキストファイルの編集、参考資料の添付、修正依頼を同じ画面で行えます。

現在は **CodexによるWebゲーム制作**に対応した初期版です。企画の確認と試遊を通じた調整が必要です。

## 言語とレイアウト

韓国語・英語・日本語・簡体字中国語・繁体字中国語に対応しています。選択は再起動後も保持され、AIの会話言語は次の作業から適用されます。既存の会話、決定内容、ファイル名、ゲーム内容は自動翻訳しません。ゲーム自体の言語は別途決めます。

ライト/ダークモード、パネルのドラッグによるサイズ変更、端にマウスを合わせると現れる折りたたみパネルを利用できます。Enterで送信、Shift+Enterで改行します。

## 更新とデータ

ダッシュボードの「更新をダウンロード」またはReleasesから新しいセットアップを取得します。現在の作業を終え、実行ウィンドウを閉じてから更新してください。アプリはバージョン別フォルダーに展開し、ショートカットを更新します。ゲーム、決定記録、ログイン情報は初期化しません。バックグラウンド自動更新は未実装です。

| 内容 | 保存場所 |
|---|---|
| アプリ本体 | `%LOCALAPPDATA%/GameHarness/apps/<version>-<build>/` |
| インストール版の新規プロジェクト | `%LOCALAPPDATA%/GameHarness/GameProjects/` |
| 決定DB・参考資料・ゲーム | 各プロジェクト内 |
| Pythonパッケージ・検索モデル | `%LOCALAPPDATA%/GameHarness/runtimes/` |
| プロジェクト一覧・会話履歴・認証 | `%LOCALAPPDATA%/GameHarness/dashboard/` |
| 自動インストールしたツール | `%LOCALAPPDATA%/GameHarness/tools/` |

既存の登録済みプロジェクト保存先は維持します。ソース/ZIP版を初めて使う場合は、アプリフォルダーと同じ親フォルダーにある `GameProjects/` が既定です。更新のために共有データを削除しないでください。バックアップはサーバー停止後にプロジェクトとdashboardフォルダーをコピーします。dashboardには認証情報が含まれるため公開しないでください。

## 接続とトラブル対応

サーバーは `127.0.0.1` で動作し、Codexの書き込み範囲をプロジェクト内に制限します。AIリクエストはOpenAIに送信するため、オフラインAIではありません。

セットアップ失敗時は最後のメッセージを確認して再実行してください。接続切れには「再接続」を使い、サーバー終了時はショートカットから開き直します。権限設定失敗時は管理者確認を完了するか、設定を再試行してください。

配布実行ファイルは現在コード署名されていません。このリポジトリのReleasesから取得し、`SHA256SUMS.txt`で照合できます。
